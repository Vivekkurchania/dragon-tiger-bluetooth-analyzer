# Dragon Tiger Bluetooth Analyzer

Two Android apps:
- **Sender**: enter Dragon/Tiger results and send them over Bluetooth.
- **Analyzer**: receive results, retain the latest 100, and show a statistical estimate based on frequency, streak, transitions and recent sequence.

This is a statistical analysis tool. It does not access or predict a game's internal RNG and its estimate is not guaranteed.

## Online build
Push this repository to GitHub. Open **Actions → Build APKs → Run workflow**. Download the `dragon-tiger-apks` artifact.
